# Pilot artefacts (reference copies)

The files in this folder are reference copies of the process artefacts from the Remitly pilot (a multi-agent software-delivery setup run between 2026-10-12 and 2026-11-07), taken from the pilot repository on 2026-11-07 and scrubbed of identifying details: personal names, e-mail addresses, the GitHub organisation and repository, and absolute machine paths have been replaced by placeholders such as `<founder>`, `<email>`, `<org>/<product-repo>` and `<repo-root>`; the product name and the role names are kept because this folder is the pilot's evidence. `CLAUDE.md`, `comms-README.md`, `comms-TEMPLATE.md` and the five `role-*.md` files are otherwise verbatim; `PROGRESS-skeleton.md` and `PLAN-skeleton.md` keep only the structure (headers, dashboard, column headers, two example rows per table) with product details replaced by `<...>`. They contain product-specific engineering rules, dates and decision ids that do not transfer, so they are not to be used directly: the generic, reusable versions live in `core/`, and the neutral description of the operating model is `../01-system-as-built.md`.
